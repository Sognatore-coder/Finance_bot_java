# Finance Director Assistant Bot 📊🤖

Telegram-бот на платформе **Java (Spring Boot)**, разработанный для автоматизации процесса знакомства клиентов с услугами финансового директора,
демонстрации кейсов и интерактивного сбора данных для заключения официального договора.

---

## 🔨 Технологический стек

Проект построен на базе современного корпоративного стека разработки:
* **Java 17** — основная языковая платформа.
* **Spring Boot 4.0.7** — модуль, обеспечивающий быстрое конфигурирование и внедрение зависимостей.
* **Spring Data JPA (Hibernate)** — слой абстракции для удобного и безопасного взаимодействия с базой данных.
* **PostgreSQL** — реляционная СУБД для постоянного хранения данных клиентов и их состояний.
* **Spring Boot Starter Mail** — модуль для автоматической отправки заполненных анкет на электронную почту через SMTP Google.
* **TelegramBots Spring Boot Starter** — библиотека для интеграции приложения с Telegram API.
* **Lombok** — библиотека для генерации шаблонного кода (геттеры, сеттеры) с целью повышения читаемости.

## 📑 Краткое описание и бизнес-логика бота

Бот работает как интерактивная воронка продаж и разделен на две логические части: **Информационную** и **Регистрационную**.

### 1. Информационный блок
* **Приветствие:** При запуске (`/start`) бот представляется помощником финансового директора.
* **Отрасли :** Выводит список сфер бизнеса, в которых у исполнителя есть сильная экспертиза.
* **Резюме:** Показывает ключевой опыт работы, достижения и квалификацию фин. директора.
* **Демо-работы:** Презентует демонстрационные работы финансового директора, описывает работу автоматизированного калькулятора финансовых моделей

### 2. Регистрационный блок 
При нажатии кнопки «Заключить договор» бот переходит в режим конечного автомата (FSM):
1. **Стирание истории:** Бот очищает предыдущую переписку в чате для конфиденциальности и фокуса пользователя на анкете.
2. **Пошаговый опрос:** Бот последовательно запрашивает:
    * ФИО
    * Страна,Город проживания / ведения бизнеса
    * Отрасль бизнеса
    * Желаемый тариф
    * Срок действия договора
    * Особые пожелания и комментарии
3. **Оферта и Персональные данные:** Перед отправкой бот выводит текст согласия на обработку персональных данных.
4. **Конверсия:** После принятия оферты анкета мгновенно сохраняется в СУБД PostgreSQL, а финансовый директор получает структурированное письмо со всеми данными клиента на свой **Google Gmail**.
